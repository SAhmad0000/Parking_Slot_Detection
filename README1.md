# Parking_Slot_Detection
A simple and effective web app built with Streamlit that uses YOLOv8 object detection to monitor parking slot availability from uploaded video footage.
The app detects vehicles (cars) in real-time and displays parking status — Empty or Occupied — frame-by-frame.
<br>
<b>Features</b>
<br>
Upload and process parking lot surveillance videos (.mp4 format).<br>
Detects cars using YOLOv8 object detection model.<br>
Displays live detection with bounding boxes.<br>
Shows real-time parking status (Empty/Occupied with car count).<br>
Visual progress bar during video processing.<br>
Works on Streamlit Cloud with lightweight setup.<br>
